# Handwritten Digit Recognition Using Neural Networks

## Description
A simple artificial neural network built with Python to recognize handwritten digits from 0 to 9.

## Technologies Used
- Python
- NumPy
- Scikit-learn

## How It Works
1. Loads handwritten digit images.
2. Trains a neural network for 300 epochs.
3. Predicts digits from 0 to 9.
4. Calculates training accuracy.

## Results
- **Training Accuracy:** 98.39%
- **Input Layer:** 64 neurons
- **Hidden Layer:** 32 neurons
- **Output Layer:** 10 neurons

## How to Run

Install the required libraries:
```bash
pip install numpy scikit-learn
```

Run the program:
```bash
python handwritten_digit_recognition.py
```
